# RTX 5070 Ti / Instinct MI100 / MI210 調査記録

調査日: 2026-11-13。3構成を追加し、合計22構成。既存19構成のレコードは変更していない。追加した公称・算出レコードは48件、公開実測は12件。全体では公称・算出412件、実測定義42項目・実測値43件となる。共通GPU/Matrix欄への別名対応を含み、件数は独立した測定の数を意味しない。

## 対象と主なメーカー値

| 項目 | RTX 5070 Ti desktop reference clocks | MI100 PCIe | MI210 PCIe |
|---|---:|---:|---:|
| メモリ GB | 16 GDDR7 | 32 HBM2 | 64 HBM2e |
| 公表帯域 GB/s | 896 | 1200 | 1600 |
| ボード電力 W | 300 | 300 | 300 |
| 非行列 FP64 TFLOPS | 0.6859375（算出） | 11.5 | 22.6 |
| 非行列 FP32 TFLOPS | 43.9 | 23.1 | 22.6 |
| 非行列 FP16 TFLOPS | 43.9 | 46.14144（算出） | 45.2608（算出） |
| Matrix FP32 TFLOPS | 未公表 | 46.1 | 45.3 |
| Matrix FP64 TFLOPS | 未公表 | 非対応 | 45.3 |
| Matrix FP16 → FP32、dense TFLOPS | 87.9 | 184.6 | 181 |
| Matrix BF16 → FP32、dense TFLOPS | 87.9 | 92.3 | 181 |
| Matrix INT8 → INT32、dense TOPS | 351.5 | 184.6 | 181 |

RTX 5070 TiはLaptop、OC製品、Founders Editionを混同しない。パートナー製品で寸法・スロット数が異なるためスロット数は未確定。CCは12.0。FP16蓄積とFP32蓄積、denseとsparseを個別登録した。FP16→FP16 sparseは351.5、FP8→FP16 denseは351.5、FP4 sparseは1406。丸め済み公表値を機械的に倍にしていない。

AMDはCUDA固有欄を `x` とし、共通GPU/Matrix欄に登録。MI100は120 CU、MI210は104 CU、どちらも単一GPU・単一GCDのPCIeボード。MI250の2 GCD OAM構成とは別物。帯域は公式PDFの丸め値を採用し、メモリクロックから算出される1228.8/1638.4 GB/sは別フィールドに保存。

非行列FP16は `CU × 4 SIMD × 16 lanes × 2 packed FP16 × 2 FLOPs/FMA × boost MHz / 10^6` の最大クロック・毎周期発行モデル。メーカーMatrixピークや実測と区別し、kind=derivedと計算条件を記録。RTX FP64は白書FP32/64の算出。表の計算性能表示だけ最大小数1桁で、保存精度は維持する。

## 資料間の相違

MI100の[製品SKUページ](https://www.amd.com/en/products/accelerators/instinct/mi100.html)にはMatrix FP32=23.1、INT8/INT4=92.3とある。一方、[公式製品PDF](https://www.amd.com/content/dam/amd/en/documents/instinct-business-docs/product-briefs/instinct-mi100-brochure.pdf)は46.1 / 184.6、[ROCmアーキテクチャ表](https://rocm.docs.amd.com/en/latest/reference/gpu-arch/mi100.html)もMatrix FP32=46.1である。公式PDFと命令レートに基づく値を採用し、SKUページの異なる値も `reported_alternate_peaks` に保持した。INT4は広告値専用項目で、ネイティブINT4 Matrix命令の性能として扱わない。

## 公開実測

ローカル実機での測定ではなく、以下の著者・メーカー公表値。

### RTX 5070 Ti: Qwen3-8B NVFP4

[Knoop / Holtmann, arXiv:2601.09527v1](https://arxiv.org/html/2601.09527v1)、2026-01-14公表、Appendix A Table 16/API、Table 15/RAGの単一GPU行。

| 入力/出力 tokens | 同時実行数 | 合計出力 tokens/s | TTFT ms |
|---|---:|---:|---:|
| API 256/256 | 32 | 1986.6 | 170 |
| API 256/256 | 64 | 2899.1 | 237 |
| API 256/256 | 128 | 3553.6 | 361 |
| RAG 8192/最大512 | 8 | 210.8 | 5228 |

vLLM 0.12、CUDA 12.9、cuDNN 9.x、driver 570.x以上、AIPerf 0.3.0、VAST.ai実機、max_num_batched_tokens=8192、dynamic batching。RAGはPoisson到着。CPU/OS、ドライバ完全版、ボードOC、測定電力、モデルhash、試行反復数は未特定。TTFTの集計統計も確定せず、独立したP95/P99列から区別。合計tokens/sは単一ユーザーの生成速度やllama-bench tg512とは異なる。要約本文の丸め値よりAppendixの該当表を優先した。

### MI100 / MI210: Dell R750xa

[Dell Performance Labs: HPC Application Performance on R750xa with MI210](https://infohub.delltechnologies.com/es-es/p/hpc-application-performance-on-dell-poweredge-r750xa-servers-with-the-amd-instinct-tm-mi210-accelerator/)、2022-08-12公表。英語URLは別ページへ転送されるため、本文が読めるスペイン語ロケールの英語記事を参照。

| 単一GPU、TFLOPS | MI100 | MI210 |
|---|---:|---:|
| DGEMM | 7.9 | 未採用 |
| SGEMM | 未掲載 | 32.2 |
| HPL | 6.4 | 18.2 |

PowerEdge R750xa、2×Xeon Gold 6338、512GB RAM、Rocky Linux 8.4、GPU driver 5.13.20.5.1、ROCm/rocBLAS 5.1.3、SMT無効、Performance profile、300W TDP。ホストに複数枚搭載されていても本文の単一GPU測定値だけを転記。HPLはROCm 5.1.3でコンパイル。問題サイズ・NB・反復回数・実測日は未掲載で、公表日を測定日として捏造しない。

DGEMM 28.3の本文はMI210記事内でMI250と表記されている。図の直接取得もHTMLへ転送され数値を照合できなかったため、28.3は採用しない。MI100のSGEMMは「約9%差」から逆算しない。多GPU値を枚数で割る処理もしていない。
